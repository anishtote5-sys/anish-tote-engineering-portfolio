# Anish Tote - Engineering Portfolio

A responsive personal portfolio for Anish Tote, an Electronics and
Communication Engineering student focused on embedded systems, PLC automation,
digital design, and applied AI.

## Highlights

- Recruiter-focused one-page narrative
- Animated engineering-system visual language
- Responsive layouts for desktop, tablet, and mobile
- Accessible focus states and reduced-motion support
- Downloadable résumé and direct email/phone actions
- Dynamic Open Graph metadata with a custom social preview card

## Tech

- React 19
- Next.js 16
- vinext and Vite
- TypeScript
- CSS animations and view timelines
- Cloudflare Workers-compatible output

## Run locally

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Validate

```bash
npm run build
npm test
```

## Project structure

- `app/page.tsx` - portfolio content and semantic structure
- `app/globals.css` - visual system, motion, and responsive behavior
- `app/layout.tsx` - metadata and social preview configuration
- `public/Anish-Tote-Resume.pdf` - downloadable résumé
- `public/og.png` - social sharing image
